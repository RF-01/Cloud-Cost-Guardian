## IAM policy simulator

`iam simulate-principal-policy` on the live roles, one action and one resource ARN per case. Resource tags, request tags, tag keys and DynamoDB keys are passed as context entries: the simulator does not read the tags of real resources, so every tag condition is evaluated on the values given here.
